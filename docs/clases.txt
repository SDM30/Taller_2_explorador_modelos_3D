Node <|-- BaseCamera
Node <|-- VisualObject
VisualObject <|-- Mesh
Mesh <|-- WavefrontOBJ
VisualObject <|-- Light
BaseCamera <|-- KeyboardTrackballCamera

VisualObject "1" *-- "0..*" Node : Children
World "1" *-- "0..1" BaseCamera : Camera
World "1" *-- "0..*" Node : Nodes
World ..> Light : configura

note as N1
  Node: clase base abstracta del grafo de escena
  (caja de contenimiento y dibujo).
  VisualObject: nodo con transformaciones e hijos
  (grafo de escena recursivo).
  WavefrontOBJ: malla cargada desde archivo .obj.
  World: motor GLUT, crea la ventana, registra
  los callbacks y ejecuta el bucle principal.
end note
